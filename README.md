# Godot web/mobile starter

A small GDScript-first 2D starter for browser and touch-screen play. Open the portrait demo, move the teal diamond with WASD/arrows or the one-thumb joystick, then pause and restart. The default Web build uses Godot's Compatibility renderer and does not load a Rust extension.

## Run the demo

Install **Godot 4.5.1** and its matching **Web export templates**, and put `godot` on your PATH. For generator tests, install `uv` or use your existing Python to run `python -m unittest tests.test_generate_starter`. No Docker or Rust is required for the default path.

```bash
make ci          # generator, import, smoke, fixtures, input and Web export
make serve-web   # after export: http://127.0.0.1:8000
```

The exported files are under `build/web/`. `make smoke` prints `[SMOKE OK]`; `make fixtures` prints `[FIXTURES OK]`. Use a local HTTP server: opening `index.html` with `file://` does not load the game. For only the Godot checks, run `make gdscript-ci` (no Web templates needed).

The demo starts on a title screen. Enter/Space or START begins play; WASD or arrow keys and the touch joystick move. P/Escape or PAUSE pauses; Enter/Space or RESUME resumes; R or RESTART resets the demo. Losing window focus pauses and releases held inputs. Gameplay advances from Godot's 60 Hz `_physics_process`; movement uses elapsed physics time. The demo is not a complete game.

## Make a separate game

The generator creates a **new** destination; it will not overwrite an existing directory or edit this checkout:

```bash
uv run --no-sync python scripts/generate_starter.py --name "My Game" /absolute/path/to/new-game
cd /absolute/path/to/new-game
make ci
```

The generated project includes the Godot project, Makefile and optional Rust sources, but not `.git`, `.godot`, extension binaries, caches or private reports. `source-provenance.json` records the template base commit and `dirty_source` flag. When that flag is true, the commit alone cannot reproduce the generated bytes. Initialize Git yourself if needed; the generator does not. Do not run this generator against a destination you want to keep.

## Where to change things

- `godot/scripts/Main.gd`: demo lifecycle, drawing and the 60 Hz update.
- `godot/adapters/input_adapter.gd`: normalized keyboard/touch input and release ownership.
- `godot/core/`: existing typed state, events and fixture seam; game-specific rules belong in a consumer, not the generic state.
- `godot/export_presets.cfg`: extension-free, single-threaded Web preset.
- `rust/`: optional native-only experiment. `make native-smoke` builds and installs the Linux native extension deliberately. **Do not run it before a default Web import/export:** the native extension is not a Web export dependency.

Read [verification status](docs/verification.md) for observed commands and remaining browser/device checks. [Architecture](docs/architecture.md) documents the typed seam; [Rust guide](docs/rust-gdext.md) describes the opt-in native path. The starter adds no game hosting or offline/PWA workflow. This repository's existing documentation workflow publishes to GitHub Pages on pushes to `main`; none of the commands above trigger that deployment.
